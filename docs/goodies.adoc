== Launch an application

[source,toml]
----
[mode.main.binding]
alt-enter = 'exec-and-forget Start-Process powershell.exe'
----

== Keep a specific application floating

[source,toml]
----
[[on-window-detected]]
if.app-id = 'notepad.exe'
run = 'layout floating'
----

== Query windows from PowerShell

[source,powershell]
----
$windows = .\aerospace.exe list-windows --all --json | ConvertFrom-Json
$windows
----

See xref:guide.adoc[the guide] and xref:commands.adoc[command references] for configuration and scripting details.
