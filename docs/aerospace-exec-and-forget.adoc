== Synopsis
[verse]
// tag::synopsis[]
exec-and-forget <powershell-script>
// end::synopsis[]

== Description
// tag::body[]
Run the remainder of the configuration string as a PowerShell script without waiting for termination. Stdout, stderr and the eventual script exit code are not captured.

[source,toml]
----
[mode.main.binding]
alt-enter = 'exec-and-forget Start-Process notepad.exe'
----

The script is supplied through PowerShell's UTF-16 encoded-command interface. The remainder of the TOML command string is preserved; use PowerShell quoting inside that string. This command is available in configuration callbacks and bindings, not as a standalone CLI command or an `eval` command.
// end::body[]
